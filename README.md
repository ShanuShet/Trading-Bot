# Binance Futures Order Bot

## Overview
A CLI-based trading bot for Binance USDT-M Futures Testnet.
Supports market, limit, and stop-limit orders with logging and validation.

## Features
- Binance Futures Testnet (USDT-M)
- Market Orders
- Limit Orders
- Stop-Limit Orders (Advanced)
- Buy & Sell support
- Input validation
- Structured logging
- Modular Python architecture


## Setup
1. Create a Binance Futures Testnet account
2. Generate API Key & Secret
3. Add them to `config.py`
4. Install dependencies: pip install -r requirements.txt



## Run
python run_bot.py



## Notes
- Uses Binance Futures Testnet only
- API keys are excluded using `.gitignore`
