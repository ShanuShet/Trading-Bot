# Binance Futures Testnet Trading Bot

## Overview
A simplified Python trading bot for Binance USDT-M Futures Testnet.
Supports Market and Limit orders with Buy/Sell functionality.

## Features
- Binance Futures Testnet (USDT-M)
- Market & Limit orders
- Buy & Sell
- CLI-based interaction
- Logging of API responses and errors

## Setup
1. Create Binance Futures Testnet API key
2. Add keys to `config.py`
3. Install dependencies:

## pip install -r requirements.txt
4. Run the bot:

python basic_bot.py

## Notes
- Uses testnet funds only
- Logging stored in `bot.log`
- API keys are excluded from version control
